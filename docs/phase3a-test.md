# 第 3a 阶段测试说明：单窗口远控

## 1. 编译

没有新的 vcpkg 依赖（分块压缩用的是 UltraVNC 本来就依赖的 zstd）。新增文件：

| 文件 | 用途 |
|---|---|
| `common/WindowProto.*` | 窗口通道协议、分块比较/打包/压缩（两端共用） |
| `winvnc/winvnc/vncWindowCapture.*` | 窗口捕获：WGC，失败时 PrintWindow；弹出窗口合成 |
| `winvnc/winvnc/vncWindowSession.*` | 列窗口、捕获线程、分块发送、键鼠注入 |
| `vncviewer/ClientConnectionWindow.cpp` | 查看器：选择窗口对话框、画布显示 |

服务端额外链接 `dwmapi`（源文件里已有 `#pragma comment`）。WGC 的接口头文件来自 Windows SDK；**建议用 SDK 10.0.22000 或更新版本**编译，这样 Win11 上能去掉黄框（旧 SDK 也能编译，只是黄框一直都在）。

测试：`tests/window_proto`（协议和分块，Linux）、`tests/window_e2e`（服务端窗口会话的端到端测试，用 MinGW 编译、在 Wine 里跑，走的是 PrintWindow 路径）。我这里都跑过，全部通过。

## 2. 使用

查看器标题栏右键（系统菜单）→ **Single Window...** → 在列表里选一个窗口 → Show。菜单前面打勾表示正在显示单个窗口；再点一次回到整个桌面。

前提：查看器颜色选「Full colors」（32 位）；视频模式要先关掉（两者暂时不能同时用）。

## 3. 看日志

服务端日志（`window:` 开头）：
```
window: session 1 started, capture by Windows.Graphics.Capture     ← 或 PrintWindow
```
如果是 `PrintWindow`，前面还会有一行 `using PrintWindow: ...` 说明 WGC 为什么不可用。**请告诉我你那边用的是哪一种**，尤其是服务端以 Windows 服务方式运行时（以 SYSTEM 身份调用 WGC 是否可行，我这里没法验证）。

## 4. 测试用例

### 基本功能
| # | 操作 | 预期 |
|---|---|---|
| 1 | 选一个记事本窗口 | 查看器只显示记事本，大小和远程窗口一致；文字清晰（无损） |
| 2 | 在记事本里打字、选中文字、滚动 | 正常，响应及时 |
| 3 | 用别的窗口**挡住**远程的记事本 | 查看器里记事本仍然完整显示（WGC）。如果是 PrintWindow 模式，也应完整 |
| 4 | 点记事本的「文件」菜单、右键菜单 | 菜单出现在查看器画面里，可以点选 |
| 5 | 打开「另存为」对话框 | 对话框合成进画面；如果对话框超出记事本窗口，画布会变大，查看器窗口跟着变大 |
| 6 | 远程调整记事本窗口大小 / 最大化 | 查看器画面跟着变 |
| 7 | 远程把记事本**最小化** | 查看器弹出「是否还原」，点「是」后窗口还原并继续显示 |
| 8 | 远程**关闭**记事本 | 查看器回到整个桌面，提示窗口已关闭 |
| 9 | 菜单再点一次「Single Window...」 | 回到整个桌面，画面完整 |

### 输入限制
| # | 操作 | 预期 |
|---|---|---|
| 10 | 远程有别的窗口在前台，在查看器里直接打字 | 记事本被切到前台，字打进记事本 |
| 11 | 在查看器画布的灰色空白处（窗口以外）点击 | 远程没有任何反应 |
| 12 | 在记事本里按住鼠标拖选文字，拖出画面边缘再松开 | 选中正常结束，没有卡住的鼠标键 |
| 13 | 只看模式（view only）的查看器 | 能看，不能操作 |

### 其他程序和情况
| # | 操作 | 预期 |
|---|---|---|
| 14 | 浏览器（Chrome/Edge）、Office、资源管理器 | 都能正常显示和操作 |
| 15 | 远程弹出 UAC 提示或锁屏，再回来 | 期间画面暂停，回来后继续 |
| 16 | 选窗口时该窗口已经不存在了 | 提示窗口无法显示 |
| 17 | 新查看器连原版服务端 | 菜单提示服务端不支持 |
| 18 | 窗口模式下开视频模式 / 视频模式下开窗口模式 | 提示先关掉另一个 |
| 19 | 慢速网络下用单窗口模式 | 帧率下降，但画面始终完整、不花屏 |
