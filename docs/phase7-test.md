# 第 7 阶段测试说明：媒体设置、重连恢复、中文界面

断点续传和拖到资源管理器的测试用例在 `docs/phase6-test.md` 的第 6、7 节。

## 1. 编译

新增文件（已加入 Visual Studio 工程和 CMake）：`vncviewer/MediaSettings.*`、`vncviewer/UiText.*`、`vncviewer/UiTextTable.inc`（生成的，由 `vncviewer/uitext/gen.py` 生成）。没有新的依赖。

改了翻译或新加 `Tr()` 文字后，运行 `python3 vncviewer/uitext/gen.py` 重新生成表（缺翻译时会报错）。

测试：`tests/uitext`、`tests/fileman_window`（`UVNC_UI_LANG=zh sh tests/fileman_window/run.sh` 会截一张中文界面的图）。

## 2. 媒体设置

| # | 操作 | 预期 |
|---|---|---|
| M1 | 系统菜单 → 媒体设置 | 对话框显示当前设置（第一次是默认：20 Mbps、60 帧、自动、128 kbps、两个勾选框都勾上） |
| M2 | 把最大码率改成 5，帧率改成 30，打开视频模式 | 服务端日志：`streaming ... at 30 fps`，码率不超过 5000 kbps |
| M3 | 编码格式选 H.264，打开视频模式 | 查看器日志 `requested, codecs H.264`；用 H.264 |
| M4 | 编码格式选 AV1，但服务端显卡不支持 AV1 | 服务端退回 H.264，画面正常 |
| M5 | 最大码率填 0 或 500，点确定 | 提示范围 1–200，不关闭对话框 |
| M6 | 声音码率改成 192，打开远程声音 | 服务端日志 `... 192 kbps AAC` |
| M7 | 取消「听声音时把远程静音」，打开远程声音 | 远程扬声器照常出声 |
| M8 | 关掉查看器再打开，看媒体设置 | 设置都还在 |

## 3. 重连后自动恢复

| # | 操作 | 预期 |
|---|---|---|
| A1 | 打开视频模式和远程声音，拔网线几秒再插上（开着自动重连） | 重连后视频模式和远程声音自动重新打开，菜单上的勾也恢复 |
| A2 | 在媒体设置里取消「重新连接后自动恢复」，重复 A1 | 重连后是普通画面、没有声音 |
| A3 | 断线前已经手动关掉了视频模式 | 重连后不会打开视频模式 |

## 4. 中文界面

查看器的语言选「中文」（或用内置英文、而 Windows 是中文）时：

| # | 检查 | 预期 |
|---|---|---|
| C1 | 系统菜单 | 视频模式（显卡）、单窗口...、远程声音、媒体设置... |
| C2 | 文件传输窗口 | 标题、列名、按钮、提示文字、右键菜单、状态栏、队列状态、冲突对话框都是中文；文字没有被截断 |
| C3 | 删除、重命名失败、服务端拒绝等提示 | 中文（Windows 自己的错误说明本来就是中文） |
| C4 | 视频模式 / 单窗口 / 远程声音的各种提示 | 中文 |
| C5 | 媒体设置对话框 | 中文，布局正常 |
| C6 | 查看器语言选繁体中文 | 以上都是繁体 |
| C7 | 查看器语言选德语等其他语言 | 这些新文字显示英文（没有其他语言的翻译） |
